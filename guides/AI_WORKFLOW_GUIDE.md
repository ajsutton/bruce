# AI Workflow Guide

## Generated project

`SmartHome.xcodeproj` is generated by XcodeGen and gitignored.

```sh
just generate
just open
```

Edit `project.yml`, never the generated project.

## Commands

```sh
just format
just format-check
just build
just build-mac
just build-ios
just test
just test-mac
just test-ios
```

Optional test filters are a test class or `ClassName/testMethod`:

```sh
just test-mac ProjectSetupTests
```

## Test output

Capture significant test runs:

```sh
mkdir -p .agent-tmp
just test 2>&1 | tee .agent-tmp/test-output.txt
```

## Before committing

1. Run `just format`.
2. Run `just format-check`.
3. Run the relevant builds and tests.
4. Fix all compiler warnings; warnings are errors in project settings.
5. Run the required reviewer cycle from `AI_ASSISTANT_GUIDE.md`.

There is no SwiftLint baseline. Do not create one or weaken thresholds to make a change pass.
